Commandes

Clavier

  • ↑/W/Z accélérer
  • ↓/S freiner, marche arrière
  • ←→/AD/Q diriger
  • Espace/Maj boost (fait chauffer)
  • R (maintenir) réparer
  • Tab/E choisir le système à réparer
  • C caméra poursuite / cockpit
  • T/Retour arrière se replacer sur la piste
  • Échap/P pause

Manette

  • Gâchette droite : accélérer
  • Gâchette gauche : freiner
  • Stick gauche : diriger
  • A / RB : boost
  • X (maintenir) : réparer
  • Y / LB : système à réparer
  • B : caméra · Start : pause
  • Select / clic stick : se replacer

Téléphone / tablette

  • Tenez le téléphone en paysage (plein écran automatique)
  • Joystick : glissez le pouce gauche à gauche / à droite
  • Inclinaison : tournez le téléphone comme un volant
  • GAZ / FREIN / BOOST / 🔧 RÉPARER : maintenir
  • Glissez le pouce de GAZ vers FREIN sans le lever
  • ⟳🔧 système à réparer · ↺ se replacer · 🎥 caméra · ⏸ pause
  • Option « Accélérateur automatique » pour jouer d'un pouce

Meta Quest 3

  • Standard : gâchette droite accélère, gâchette gauche freine, stick pour diriger
  • Leviers : chaque gâchette pousse un réacteur — la différence fait tourner ; poignées = freins
  • A : boost · B : pause
  • X ou poignées (standard) maintenues : réparer
  • Y : système à réparer
  • Clic d'un stick : se replacer sur la piste
  • Maintenir le bouton Meta : recentrer la vue

Avaries et réparations

Chocs contre les parois, les arches ou les autres pods, et tirs des pillards embusqués sur les crêtes endommagent vos moteurs, votre direction et votre coque. Un pod abîmé accélère moins, tourne moins bien et plafonne en vitesse. Des pannes surviennent aussi en course (incendie moteur, direction bloquée, injecteur encrassé). Maintenez la touche de réparation : pendant ce temps la poussée est limitée et le boost indisponible. Si la coque tombe à zéro, le pod explose et repart quelques secondes plus tard.
